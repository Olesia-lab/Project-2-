Co dokładnie budujemy

Dwaj gracze mają pionki X i O. X zaczyna pustą planszę. Wybór kolumny opuszcza pionek na najniższe wolne pole. Cztery własne pionki w poziomie, pionie albo po dowolnej przekątnej kończą partię zwycięstwem. Pełna plansza bez zwycięzcy daje remis. Pełna kolumna jest niedozwolonym ruchem. Po zakończeniu partii nie można wykonać kolejnego ruchu.

Wariant klasyczny ma 6 wierszy i 7 kolumn. Nasza modyfikacja dodaje planszę 8 × 9 przy tych samych zasadach wygranej. Pozwala to porównać maksymalnie 7 oraz 9 wyborów w jednej turze. Sprawdzamy wpływ tej zmiany na obliczenia. Nie zakładamy z góry konkretnego wzrostu czasu.

Każdy gracz może być człowiekiem albo jedną z trzech strategii. W ten sposób otrzymujemy grę człowiek kontra człowiek przy jednym komputerze, człowiek kontra AI oraz AI kontra AI. Człowiek wpisuje numer kolumny. Pionki i plansza są tekstowe.

Wybór alphabeta oznacza tę samą strategię Minimax z optymalizacją. Trzecią odrębną strategią jest Monte Carlo. Dodatki C++ odpowiadają ustnym przykładom wykładowcy. Bez dokładnej punktacji nie da się zagwarantować określonej oceny.

Składnia potrzebna do czytania kolejnych plików

#include dołącza deklaracje. Plik .hpp opisuje klasę i dostępne operacje, a .cpp zawiera ich działanie. #pragma once zapobiega wielokrotnemu dołączeniu nagłówka. Klasa łączy dane i funkcje, zwane metodami. public udostępnia metody innym częściom programu. Dane przed public są prywatne.

std::vector jest tablicą o ustalanym podczas działania rozmiarze. Wektor wektorów zapisuje wiersze planszy. std::array ma liczbę elementów znaną podczas kompilacji. int przechowuje liczby całkowite, bool wartości prawda/fałsz, double także części ułamkowe. auto pozwala kompilatorowi ustalić typ na podstawie przypisanej wartości.

const Board& udostępnia istniejącą planszę bez kopiowania i bez prawa zmiany przez tę nazwę. Board child = board tworzy osobną kopię. const po metodzie zabrania zmieniać jej zwykłe pola. :: wskazuje klasę lub przestrzeń nazw. Kropka wywołuje metodę obiektu, a -> obiektu wskazywanego przez wskaźnik.

std::optional<int> może przechowywać liczbę albo być pusty. W wyniku partii pusty oznacza grę trwającą, 0 remis, a 1 lub 2 zwycięzcę. if (result) sprawdza obecność wartości, więc również remis 0 spełnia ten warunek. *result odczytuje liczbę dopiero po potwierdzeniu jej obecności. W wyborze ruchu pusty wynik oznacza brak ruchów.

std::unique_ptr zarządza jednym obiektem i automatycznie go usuwa. std::make_unique tworzy taki obiekt. std::move przekazuje jego własność, zamiast kopiować wskaźnik. virtual pozwala wywołać właściwą metodę konkretnej strategii przez wspólny typ Strategy. Wirtualny destruktor umożliwia jej poprawne usunięcie. override sprawdza, czy rzeczywiście zastępujemy metodę rodzica.

++ zwiększa o jeden, -- zmniejsza, == porównuje, a = przypisuje. ! odwraca warunek, && wymaga obu warunków, a || przynajmniej jednego. warunek ? a : b wybiera wartość a lub b. return kończy funkcję i może oddać wynik. Nawiasy klamrowe wyznaczają bloki, a średnik kończy instrukcję lub definicję klasy.

Funkcja lambda jest małą funkcją zapisaną w miejscu użycia. W sortowaniu [this] pozwala jej odczytać szerokość bieżącej planszy. throw zgłasza błąd, a try i catch przechwytują go, aby wypisać opis. steady_clock mierzy upływ czasu bez przestawiania przez zmianę daty systemowej.

#include "Board.hpp"
#include <algorithm>
#include <array>
#include <cstdlib>
#include <stdexcept>

Board::Board(int rows, int columns) {
    if (rows < 4 || columns < 4 || rows > 8 || columns > 9)
        throw std::invalid_argument("Wymiary musza miescic sie w zakresie 4..8 na 4..9.");
    cells_.assign(rows, std::vector<int>(columns, 0));
}

std::vector<int> Board::legalMoves() const {
    std::vector<int> moves;
    if (result_) return moves;
    for (int column = 0; column < columns(); ++column)
        if (cells_[0][column] == 0) moves.push_back(column);
    std::stable_sort(moves.begin(), moves.end(), [this](int a, int b) {
        return std::abs(2 * a - columns() + 1) < std::abs(2 * b - columns() + 1);
    });
    return moves;
}

bool Board::play(int column) {
    if (result_ || column < 0 || column >= columns() || cells_[0][column] != 0)
        return false;
    int row = rows() - 1;
    while (cells_[row][column] != 0) --row;
    cells_[row][column] = player_;
    ++moves_;
    const std::array<std::array<int, 2>, 4> directions{{{0, 1}, {1, 0}, {1, 1}, {1, -1}}};
    for (const auto& direction : directions) {
        int count = 1;
        for (int sign : {-1, 1}) {
            int r = row + sign * direction[0];
            int c = column + sign * direction[1];
            while (r >= 0 && r < rows() && c >= 0 && c < columns() && cells_[r][c] == player_) {
                ++count;
                r += sign * direction[0];
                c += sign * direction[1];
            }
        }
        if (count >= 4) result_ = player_;
    }
    if (!result_ && moves_ == rows() * columns()) result_ = 0;
    if (!result_) player_ = 3 - player_;
    return true;
}

MetodaCo należy zrozumieć
ZachłannaSprawdza własne ruchy, premiuje natychmiastową wygraną i karze ruch pozwalający przeciwnikowi wygrać od razu. Pozostałe pozycje ocenia punktacją. To płytka strategia taktyczna, obejmująca również odpowiedź przeciwnika.
MinimaxNasza tura wybiera największą ocenę, a tura przeciwnika najmniejszą. Ocena zawsze dotyczy gracza, który rozpoczął wyszukiwanie. Głębokość 1 sprawdza jeden własny ruch, a głębokość 2 także odpowiedź przeciwnika.

Heurystyka, czyli przybliżona ocena niedokończonej partii, sprawdza wszystkie odcinki czterech pól. Jeden, dwa i trzy własne pionki bez pionka przeciwnika dają 1, 10 i 100 punktów. Heurystyka może przeceniać zagrożenie na polu, na które pionek nie może jeszcze spaść.

Legalne ruchy sprawdzamy od środka planszy. Przy równych ocenach zachowujemy pierwszy. Pojedyncze wyszukiwanie Minimax ma limit 2000 ms, sprawdzany przy wejściu do kolejnego węzła. constexpr int winScore = 1000000;

int evaluate(const Board& board, int player) {
    const std::array<int, 5> weights{0, 1, 10, 100, winScore};
    const std::array<std::array<int, 2>, 4> directions{{{0, 1}, {1, 0}, {1, 1}, {1, -1}}};
    int score = 0;
    for (int row = 0; row < board.rows(); ++row) {
        for (int column = 0; column < board.columns(); ++column) {
            for (const auto& direction : directions) {
                int endRow = row + 3 * direction[0];
                int endColumn = column + 3 * direction[1];
                if (endRow >= board.rows() || endColumn < 0 || endColumn >= board.columns()) continue;
                int own = 0;
                int enemy = 0;
                for (int i = 0; i < 4; ++i) {
                    int cell = board.at(row + i * direction[0], column + i * direction[1]);
                    if (cell == player) ++own;
                    else if (cell != 0) ++enemy;
                }
                if (enemy == 0) score += weights[own];
                if (own == 0) score -= weights[enemy];
            }
        }
    }
    return score;
}

int terminalScore(int result, int player, int depth) {
    if (result == 0) return 0;
    return result == player ? winScore + depth : -winScore - depth;
}

std::optional<int> GreedyStrategy::choose(const Board& board, SearchStats& stats) {
    stats = {};
    stats.states = 1;
    std::optional<int> best;
    int bestScore = -infinity;
    int player = board.currentPlayer();

int MinimaxStrategy::search(const Board& board, int depth, int alpha, int beta, SearchStats& stats) {
    ++stats.states;
    if (std::chrono::steady_clock::now() >= deadline_) {
        stats.complete = false;
        return 0;
    }
    if (board.result()) return terminalScore(*board.result(), rootPlayer_, depth);
    if (depth == 0) return evaluate(board, rootPlayer_);
    bool maximizing = board.currentPlayer() == rootPlayer_;
    int value = maximizing ? -infinity : infinity;
    for (int column : board.legalMoves()) {
        Board child = board;
        child.play(column);
        int score = search(child, depth - 1, alpha, beta, stats);
        if (!stats.complete) return 0;
        if (maximizing) {
            value = std::max(value, score);
            alpha = std::max(alpha, value);
        } else {
            value = std::min(value, score);
            beta = std::min(beta, value);
        }
        if (pruning_ && alpha >= beta) {
            ++stats.cutoffs;
            break;
        }
    }
    return value;
}

std::optional<int> MinimaxStrategy::choose(const Board& board, SearchStats& stats) {
    stats = {};
    stats.states = 1;
    auto moves = board.legalMoves();
    if (moves.empty()) return std::nullopt;
    deadline_ = std::chrono::steady_clock::now() + std::chrono::milliseconds(limitMs_);
    rootPlayer_ = board.currentPlayer();
    int bestScore = -infinity;
    int alpha = -infinity;
    int best = moves.front();
    for (int column : moves) {
        Board child = board;
        child.play(column);
        int score = search(child, depth_ - 1, alpha, infinity, stats);
        if (!stats.complete) {
            stats.score = 0;
            return moves.front();
        }
        if (score > bestScore) {
            bestScore = score;
            best = column;
        }
        if (pruning_) alpha = std::max(alpha, bestScore);
    }
    stats.score = bestScore;

}

MonteCarloStrategy::MonteCarloStrategy(int simulations, unsigned seed)
    : simulations_(simulations), generator_(seed) {

std::optional<int> MonteCarloStrategy::choose(const Board& board, SearchStats& stats) {
    stats = {};
    stats.states = 1;
    std::optional<int> best;
    int bestScore = -simulations_ - 1;
    int player = board.currentPlayer();
    for (int column : board.legalMoves()) {
        int score = 0;
        for (int simulation = 0; simulation < simulations_; ++simulation) {
            Board trial = board;
            trial.play(column);
            ++stats.states;
            while (!trial.result()) {
                auto moves = trial.legalMoves();
                std::uniform_int_distribution<int> pick(0, static_cast<int>(moves.size()) - 1);
                trial.play(moves[pick(generator_)]);
                ++stats.states;
            }
            if (*trial.result() == player) ++score;
            else if (*trial.result() != 0) --score;
        }
        if (score > bestScore) {
            bestScore = score;
            best = column;
        }
    }
    stats.score = best ? bestScore : 0;
    return best;
}

}

    std::ofstream file(path);

std::string strategyName(const std::string& name) {
    if (name == "greedy") return "Strategia zachlanna";
    if (name == "alphabeta") return "Minimax z cieciami Alpha-Beta";
    if (name == "minimax") return "Minimax bez ciec";

void writeStats(std::ostream& file, const SearchStats& stats, int column) {
    file << "wybrana_kolumna = " << column + 1
         << "\nczas_ms = " << stats.milliseconds
         << "\nsprawdzone_stany = " << stats.states
         << "\nodciecia_galezi = " << stats.cutoffs
         << "\nstatus = " << (stats.complete ? "ukonczono" : "przerwano_limit_czasu")
         << "\nocena = " << (stats.complete ? std::to_string(stats.score) : "nieustalona") << "\n\n";

Board opening(int rows, int columns, unsigned seed, int plies) {
    Board board(rows, columns);
    std::mt19937 generator(seed);
    for (int i = 0; i < plies; ++i) {
        auto moves = board.legalMoves();
        std::uniform_int_distribution<int> pick(0, static_cast<int>(moves.size()) - 1);
        board.play(moves[pick(generator)]);
    }
    return board;
}

void runBenchmarks(int maxDepth) {
    if (maxDepth < 1 || maxDepth > 12) throw std::invalid_argument("Glebokosc 1..12.");
    auto file = openReport("pomiary_minimax.ini", "Czas i koszt wyboru ruchu przez Minimax");
    file << "opis = Kazda sekcja pomiaru opisuje jeden wybor ruchu.\n"
         << "powtorzenia = 5\nprog_nieakceptowalnej_mediany_ms = 1000\nlimit_wyszukiwania_ms = 2000\n"
         << "status_przerwania = Wynik nie opisuje ukonczonego wyszukiwania na zadanej glebokosci.\n"
         << "jednostka_oceny = Punkty heurystyki Minimax, wygrana ma wartosc okolo miliona.\n\n";
    int measurement = 0;
    int summaryId = 0;
    for (const auto size : {std::array<int, 2>{6, 7}, std::array<int, 2>{8, 9}}) {
        for (int plies : {0, 6}) {
            std::cout << "Pomiary: plansza " << size[0] << " x " << size[1] << ", ruchy otwarcia: " << plies << '\n';
            Board board = opening(size[0], size[1], 2026, plies);
            std::array<bool, 2> stopped{false, false};
            for (int depth = 1; depth <= maxDepth; ++depth) {
                std::array<std::vector<double>, 2> times;
                std::array<bool, 2> complete{true, true};
                for (int repeat = 1; repeat <= 5; ++repeat) {
                    for (bool pruning : {false, true}) {
                        int mode = pruning ? 1 : 0;
                        if (stopped[mode] || !complete[mode]) continue;
                        MinimaxStrategy strategy(depth, pruning);
                        SearchStats stats;
                        auto column = measure(strategy, board, stats);
                        file << "[pomiar_" << ++measurement << "]\nplansza = " << size[0] << " x " << size[1]
                             << "\npozycja = " << (plies == 0 ? "Pusta plansza" : "Po szesciu ruchach otwarcia")
                             << "\nruchy_otwarcia = " << plies << "\nziarno = 2026\nstrategia = "
                             << strategyName(pruning ? "alphabeta" : "minimax")
                             << "\nglebokosc_zadana = " << depth << "\npowtorzenie = " << repeat << '\n';
                        writeStats(file, stats, *column);
                        times[mode].push_back(stats.milliseconds);
                        if (!stats.complete) {
                            complete[mode] = false;
                        }
                    }
                }
                for (int mode = 0; mode < 2; ++mode) {
                    if (stopped[mode]) continue;
                    std::sort(times[mode].begin(), times[mode].end());
                    file << "[podsumowanie_" << ++summaryId << "]\nplansza = " << size[0] << " x " << size[1]
                         << "\nruchy_otwarcia = " << plies << "\nstrategia = "
                         << strategyName(mode == 1 ? "alphabeta" : "minimax")
                         << "\nglebokosc_zadana = " << depth << "\nliczba_prob = " << times[mode].size()
                         << "\nstatus = " << (complete[mode] ? "ukonczono" : "przerwano_limit_czasu")
                         << "\nmediana_czasu_ms = ";
                    if (complete[mode]) file << times[mode][times[mode].size() / 2];
                    else file << "nieustalona";
                    file << "\n\n";
                    stopped[mode] = !complete[mode] || times[mode][times[mode].size() / 2] >= 1000;
                }
                if (stopped[0] && stopped[1]) break;
            }
        }
    }
    file.close();
    std::cout << "Zapisano pomiary_minimax.ini. Status przerwano_limit_czasu oznacza niepelne obliczenie.\n";
}

void runDuels(int pairs) {
    if (pairs < 1 || pairs > 50) throw std::invalid_argument("Liczba par 1..50.");
    auto movesFile = openReport("turniej_ruchy.ini", "Przebieg partii turnieju AI");
    auto summary = openReport("turniej_podsumowanie.ini", "Wyniki pojedynkow trzech strategii AI");

              << "glebokosc_minimax = 3\nsymulacje_monte_carlo_na_kolumne = 30\nruchy_otwarcia = 6\n"
              << "status_przerwania = Wykonano pierwszy legalny ruch awaryjny.\n"
              << "jednostka_oceny_zachlannej_i_minimax = Punkty heurystyki\n"
              << "jednostka_oceny_monte_carlo = Liczba wygranych minus liczba porazek w symulacjach\n\n";
    summary << "opis = Kazdy pojedynek obejmuje pary partii ze zmiana stron na tym samym otwarciu.\n"
            << "uwaga = Ruchy awaryjne trzeba uwzglednic przy interpretacji skutecznosci AI.\n\n";
    const std::array<std::string, 3> names{"greedy", "alphabeta", "montecarlo"};
    int game = 0;
    int matchup = 0;
    for (const auto size : {std::array<int, 2>{6, 7}, std::array<int, 2>{8, 9}}) {
        for (int a = 0; a < 3; ++a) {
            for (int b = a + 1; b < 3; ++b) {
                std::cout << "Turniej: " << size[0] << " x " << size[1] << ", "
                          << strategyName(names[a]) << " kontra " << strategyName(names[b]) << '\n';
                std::array<int, 3> results{};
                int incomplete = 0;
                for (int pair = 0; pair < pairs; ++pair) {
                    unsigned seed = 2026 + pair;
                    for (int leg = 0; leg < 2; ++leg) {
                        Board board = opening(size[0], size[1], seed, 6);
                        int aPlayer = leg == 0 ? 1 : 2;
                        auto strategyA = makeStrategy(names[a], 3, 30, seed);
                        auto strategyB = makeStrategy(names[b], 3, 30, seed + 10000);
                        movesFile << "[partia_" << ++game << "]\nplansza = " << size[0] << " x " << size[1]
                                  << "\nstrategia_a = " << strategyName(names[a]) << "\nstrategia_b = " << strategyName(names[b])
                                  << "\npara = " << pair + 1 << "\nspotkanie_w_parze = " << leg + 1
                                  << "\ngracz_strategii_a = " << aPlayer << "\nziarno_otwarcia = " << seed
                                  << "\nziarno_strategii_a = " << seed << "\nziarno_strategii_b = " << seed + 10000 << "\n\n";
                        int ply = 6;
                        while (!board.result()) {
                            int player = board.currentPlayer();
                            bool isA = player == aPlayer;
                            Strategy& strategy = isA ? *strategyA : *strategyB;
                            SearchStats stats;
                            auto column = measure(strategy, board, stats);
                            if (!column || !board.play(*column)) throw std::logic_error("Nielegalny ruch AI.");
                            ++ply;
                            if (!stats.complete) ++incomplete;
                            movesFile << "[partia_" << game << ".ruch_" << ply << "]\ngracz = " << player
                                      << "\nstrategia = " << strategyName(names[isA ? a : b]) << '\n';
                            writeStats(movesFile, stats, *column);
                        }
                        int result = *board.result();
                        ++results[result == 0 ? 2 : (result == aPlayer ? 0 : 1)];
                        movesFile << "[wynik_partii_" << game << "]\nrezultat = "
                                  << (result == 0 ? "Remis" : "Wygrana") << "\nzwyciezca = "
                                  << (result == 0 ? "Brak" : strategyName(names[result == aPlayer ? a : b]))
                                  << "\nliczba_ruchow_z_otwarciem = " << ply << "\n\n";
                    }
                }
                summary << "[pojedynek_" << ++matchup << "]\nplansza = " << size[0] << " x " << size[1]
                        << "\nstrategia_a = " << strategyName(names[a]) << "\nstrategia_b = " << strategyName(names[b])
                        << "\nliczba_par = " << pairs << "\nliczba_partii = " << 2 * pairs
                        << "\nglebokosc_minimax = 3\nsymulacje_monte_carlo_na_kolumne = 30\nruchy_otwarcia = 6"
                        << "\nwygrane_a = " << results[0] << "\nwygrane_b = " << results[1]
                        << "\nremisy = " << results[2] << "\nruchy_awaryjne = " << incomplete << "\n\n";
            }
        }
    }
    movesFile.close();
    summary.close();
    std::cout << "Zapisano turniej_ruchy.ini i turniej_podsumowanie.ini.\n";
}

Pytania do przećwiczenia
  • Co jest węzłem drzewa, a co jego krawędzią? Węzłem jest stan Board, krawędzią jeden legalny ruch.
  • Dlaczego funkcja wywołuje samą siebie? Każdy ruch prowadzi do mniejszego podproblemu, z głębokością zmniejszoną o jeden.
  • Kiedy kończy się rekurencja? Po wygranej, remisie, osiągnięciu głębokości albo limitu czasu. Ostatni przypadek jest oznaczony jako nieukończony.
  • Dlaczego kopiujemy planszę? Żeby sprawdzenie jednego wariantu nie zmieniało stanu rzeczywistej gry ani innych gałęzi.
  • Po co unique_ptr i wirtualny destruktor? Gracz może posiadać obiekt jednej z różnych strategii, usuwany automatycznie przez wspólny typ.
  • Czym pusty optional różni się od wartości 0? Pusty oznacza brak wyniku, a 0 jest konkretną zapisaną wartością, tutaj remisem.
  • Czy Alpha-Beta daje inną strategię? Pomija zbędne gałęzie Minimaxu przy tej samej głębokości i ocenie. Trzecią metodą w projekcie jest Monte Carlo.
  • Co znaczy granica podejścia siłowego? W tym badaniu jest to osiągnięcie ustalonego progu czasu na określonych pozycjach i komputerze. Nie jest uniwersalną granicą całej gry.
