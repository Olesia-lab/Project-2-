Składnia potrzebna do czytania kolejnych plików

#include dołącza deklaracje. Plik .hpp opisuje klasę i dostępne operacje, a .cpp zawiera ich działanie. #pragma once zapobiega wielokrotnemu dołączeniu nagłówka. Klasa łączy dane i funkcje, zwane metodami. public udostępnia metody innym częściom programu. Dane przed public są prywatne.

std::vector jest tablicą o ustalanym podczas działania rozmiarze. Wektor wektorów zapisuje wiersze planszy. std::array ma liczbę elementów znaną podczas kompilacji. int przechowuje liczby całkowite, bool wartości prawda/fałsz, double także części ułamkowe. auto pozwala kompilatorowi ustalić typ na podstawie przypisanej wartości.

const Board& udostępnia istniejącą planszę bez kopiowania i bez prawa zmiany przez tę nazwę. Board child = board tworzy osobną kopię. const po metodzie zabrania zmieniać jej zwykłe pola. :: wskazuje klasę lub przestrzeń nazw. Kropka wywołuje metodę obiektu, a -> obiektu wskazywanego przez wskaźnik.

std::optional<int> może przechowywać liczbę albo być pusty. W wyniku partii pusty oznacza grę trwającą, 0 remis, a 1 lub 2 zwycięzcę. if (result) sprawdza obecność wartości, więc również remis 0 spełnia ten warunek. *result odczytuje liczbę dopiero po potwierdzeniu jej obecności. W wyborze ruchu pusty wynik oznacza brak ruchów.

std::unique_ptr zarządza jednym obiektem i automatycznie go usuwa. std::make_unique tworzy taki obiekt. std::move przekazuje jego własność, zamiast kopiować wskaźnik. virtual pozwala wywołać właściwą metodę konkretnej strategii przez wspólny typ Strategy. Wirtualny destruktor umożliwia jej poprawne usunięcie. override sprawdza, czy rzeczywiście zastępujemy metodę rodzica.

++ zwiększa o jeden, -- zmniejsza, == porównuje, a = przypisuje. ! odwraca warunek, && wymaga obu warunków, a || przynajmniej jednego. warunek ? a : b wybiera wartość a lub b. return kończy funkcję i może oddać wynik. Nawiasy klamrowe wyznaczają bloki, a średnik kończy instrukcję lub definicję klasy.

Funkcja lambda jest małą funkcją zapisaną w miejscu użycia. W sortowaniu [this] pozwala jej odczytać szerokość bieżącej planszy. throw zgłasza błąd, a try i catch przechwytują go, aby wypisać opis. steady_clock mierzy upływ czasu bez przestawiania przez zmianę daty systemowej.

#include "Board.hpp"
#include <algorithm>
#include <array>
#include <cstdlib>
#include <stdexcept>

Board::Board(int rows, int columns) {
    if (rows < 4 || columns < 4 || rows > 8 || columns > 9)
        throw std::invalid_argument("Wymiary musza miescic sie w zakresie 4..8 na 4..9.");
    cells_.assign(rows, std::vector<int>(columns, 0));
}

std::vector<int> Board::legalMoves() const {
    std::vector<int> moves;
    if (result_) return moves;
    for (int column = 0; column < columns(); ++column)
        if (cells_[0][column] == 0) moves.push_back(column);
    std::stable_sort(moves.begin(), moves.end(), [this](int a, int b) {
        return std::abs(2 * a - columns() + 1) < std::abs(2 * b - columns() + 1);
    });
    return moves;
}

bool Board::play(int column) {
    if (result_ || column < 0 || column >= columns() || cells_[0][column] != 0)
        return false;
    int row = rows() - 1;
    while (cells_[row][column] != 0) --row;
    cells_[row][column] = player_;
    ++moves_;
    const std::array<std::array<int, 2>, 4> directions{{{0, 1}, {1, 0}, {1, 1}, {1, -1}}};
    for (const auto& direction : directions) {
        int count = 1;
        for (int sign : {-1, 1}) {
            int r = row + sign * direction[0];
            int c = column + sign * direction[1];
            while (r >= 0 && r < rows() && c >= 0 && c < columns() && cells_[r][c] == player_) {
                ++count;
                r += sign * direction[0];
                c += sign * direction[1];
            }
        }
        if (count >= 4) result_ = player_;
    }
    if (!result_ && moves_ == rows() * columns()) result_ = 0;
    if (!result_) player_ = 3 - player_;
    return true;
}

int evaluate(const Board& board, int player) {
    const std::array<int, 5> weights{0, 1, 10, 100, winScore};
    const std::array<std::array<int, 2>, 4> directions{{{0, 1}, {1, 0}, {1, 1}, {1, -1}}};
    int score = 0;
    for (int row = 0; row < board.rows(); ++row) {
        for (int column = 0; column < board.columns(); ++column) {
            for (const auto& direction : directions) {
                int endRow = row + 3 * direction[0];
                int endColumn = column + 3 * direction[1];
                if (endRow >= board.rows() || endColumn < 0 || endColumn >= board.columns()) continue;
                int own = 0;
                int enemy = 0;
                for (int i = 0; i < 4; ++i) {
                    int cell = board.at(row + i * direction[0], column + i * direction[1]);
                    if (cell == player) ++own;
                    else if (cell != 0) ++enemy;
                }
                if (enemy == 0) score += weights[own];
                if (own == 0) score -= weights[enemy];
            }
        }
    }
    return score;
}

int terminalScore(int result, int player, int depth) {
    if (result == 0) return 0;
    return result == player ? winScore + depth : -winScore - depth;
}

std::optional<int> GreedyStrategy::choose(const Board& board, SearchStats& stats) {
    stats = {};
    stats.states = 1;
    std::optional<int> best;
    int bestScore = -infinity;
    int player = board.currentPlayer();
    for (int column : board.legalMoves()) {

int MinimaxStrategy::search(const Board& board, int depth, int alpha, int beta, SearchStats& stats) {
    ++stats.states;
    if (std::chrono::steady_clock::now() >= deadline_) {
        stats.complete = false;
        return 0;
    }
    if (board.result()) return terminalScore(*board.result(), rootPlayer_, depth);
    if (depth == 0) return evaluate(board, rootPlayer_);
    bool maximizing = board.currentPlayer() == rootPlayer_;
    int value = maximizing ? -infinity : infinity;
    for (int column : board.legalMoves()) {
        Board child = board;
        child.play(column);
        int score = search(child, depth - 1, alpha, beta, stats);
        if (!stats.complete) return 0;
        if (maximizing) {
            value = std::max(value, score);
            alpha = std::max(alpha, value);
        } else {
            value = std::min(value, score);
            beta = std::min(beta, value);
        }
        if (pruning_ && alpha >= beta) {
            ++stats.cutoffs;
            break;
        }
    }
    return value;
}

std::optional<int> MinimaxStrategy::choose(const Board& board, SearchStats& stats) {
    stats = {};
    stats.states = 1;
    auto moves = board.legalMoves();
    if (moves.empty()) return std::nullopt;
    deadline_ = std::chrono::steady_clock::now() + std::chrono::milliseconds(limitMs_);
    rootPlayer_ = board.currentPlayer();
    int bestScore = -infinity;
    int alpha = -infinity;
    int best = moves.front();
    for (int column : moves) {
        Board child = board;
        child.play(column);
        int score = search(child, depth_ - 1, alpha, infinity, stats);
        if (!stats.complete) {
            stats.score = 0;
            return moves.front();

            best = column;
        }

    }

}

MonteCarloStrategy::MonteCarloStrategy(int simulations, unsigned seed)
    : simulations_(simulations), generator_(seed) {

std::optional<int> MonteCarloStrategy::choose(const Board& board, SearchStats& stats) {
    stats = {};
    stats.states = 1;
    std::optional<int> best;
    int bestScore = -simulations_ - 1;
    int player = board.currentPlayer();
    for (int column : board.legalMoves()) {
        int score = 0;
        for (int simulation = 0; simulation < simulations_; ++simulation) {
            Board trial = board;
            trial.play(column);
            ++stats.states;
            while (!trial.result()) {
                auto moves = trial.legalMoves();
                std::uniform_int_distribution<int> pick(0, static_cast<int>(moves.size()) - 1);
                trial.play(moves[pick(generator_)]);
                ++stats.states;
            }
            if (*trial.result() == player) ++score;
            else if (*trial.result() != 0) --score;
        }
        if (score > bestScore) {
            bestScore = score;
            best = column;
        }
    }
    stats.score = best ? bestScore : 0;
    return best;
}

}

Zadanie 4. Określcie koszt i granicę przeszukiwania

Przyjmijcie oznaczenia R i C dla wierszy i kolumn, b dla liczby legalnych ruchów oraz d dla głębokości. Maksymalnie b wynosi 7 lub 9. Pełne kolumny i wcześniejsze zwycięstwa zmniejszają rzeczywiste drzewo.

ElementOszacowanie dla naszego kodu
Pełne drzewo do głębokości dNajwyżej 1 + b + b² + … + bᵈ stanów przy stałym maksymalnym b.
Czas MinimaxO(bᵈ · R · C). Liczba gałęzi rośnie wykładniczo, a kopiowanie i ocena planszy kosztują do O(R · C).
Czas Alpha-BetaTen sam najgorszy przypadek. Przy idealnej kolejności ruchów czynnik drzewa spada do rzędu b^(d/2). Nie zakładamy, że nasza kolejność zawsze to osiągnie.
Pamięć przeszukiwaniaO(d · (R · C + b)), czyli kopie plansz i listy ruchów na bieżącej ścieżce. Nie O(bᵈ), bo całego drzewa nie przechowujemy.
ZachłannaKonserwatywnie O(b² · R · C), bo sprawdza także natychmiastowe odpowiedzi.
Monte CarloKonserwatywnie O(b · s · m · R · C), gdzie s to symulacje na kolumnę, a m maksymalna liczba ruchów do końca. Pamięć zależy głównie od jednej symulowanej planszy.

    : board_(rows, columns), players_{std::move(first), std::move(second)} {}

void Game::print() const {
    for (int row = 0; row < board_.rows(); ++row) {
        for (int column = 0; column < board_.columns(); ++column)
            std::cout << ".XO"[board_.at(row, column)] << ' ';
        std::cout << '\n';
    }
    for (int column = 1; column <= board_.columns(); ++column) std::cout << column << ' ';
    std::cout << '\n';
}

void Game::run() {
    std::cout << "Gracz 1: X. Gracz 2: O.\n";
    while (!board_.result()) {
        print();
        if (players_[0] && players_[1]) waitForEnter("Nacisnij Enter, aby AI wykonalo nastepny ruch.\n");
        int player = board_.currentPlayer();
        auto& strategy = players_[player - 1];
        if (strategy) {

            auto column = measure(*strategy, board_, stats);

Opening opening(int size, unsigned seed, int plies) {
    Opening position{Board(sizes[size][0], sizes[size][1]), {}};
    std::mt19937 generator(seed);
    for (int i = 0; i < plies; ++i) {
        auto moves = position.board.legalMoves();
        if (moves.empty()) throw std::logic_error("Otwarcie zakonczylo partie.");
        std::uniform_int_distribution<int> pick(0, static_cast<int>(moves.size()) - 1);
        int column = moves[pick(generator)];
        if (!position.board.play(column)) throw std::logic_error("Nielegalny ruch otwarcia.");
        position.columns.push_back(column);
    }
    return position;
}

void playGame(Study& study, Match& match, std::ofstream& log, int game, int pair, int leg) {
    const auto started = std::chrono::steady_clock::now();
    const unsigned seed = firstSeed + pair;
    auto position = opening(match.size, seed, openingPlies);
    auto& board = position.board;
    const int aPlayer = leg + 1;
    const auto& a = bots[match.bot[0]];
    const auto& b = bots[match.bot[1]];
    std::array<std::unique_ptr<Strategy>, 2> players{
        makeStrategy(a.id, a.depth, simulations, seed),
        makeStrategy(b.id, b.depth, simulations, seed + 10000)};
    std::ostringstream gameLog;
    gameLog << std::fixed << std::setprecision(3)
            << "[partia_" << game << "]\nplansza = " << boardLabel(match.size)
            << "\nstrategia_a = " << a.legacyLabel << "\nstrategia_b = " << b.legacyLabel
            << "\npara = " << pair + 1 << "\nspotkanie_w_parze = " << leg + 1
            << "\ngracz_strategii_a = " << aPlayer << "\nziarno_otwarcia = " << seed
            << "\nziarno_strategii_a = " << seed << "\nziarno_strategii_b = " << seed + 10000
            << "\nseria = " << seriesLabel(match.depths)
            << "\nkolumny_otwarcia = " << columnsText(position.columns)
            << "\nglebokosc_a = " << a.depth << "\nglebokosc_b = " << b.depth << "\n\n";
    int ply = openingPlies;
    std::array<Moves, 2> actions{};
    while (!board.result()) {
        int player = board.currentPlayer();
        int side = player == aPlayer ? 0 : 1;
        SearchStats stats;
        auto column = measure(*players[side], board, stats);
        if (!column || !board.play(*column)) throw std::logic_error("Nielegalny ruch AI.");
        actions[side].record(stats.milliseconds, stats.complete);
        gameLog << "[partia_" << game << ".ruch_" << ++ply << "]\ngracz = " << player
                << "\nstrategia = " << bots[match.bot[side]].legacyLabel << '\n';
        writeStats(gameLog, stats, *column);
    }
    const int winner = *board.result();
    const double time = std::chrono::duration<double, std::milli>(
        std::chrono::steady_clock::now() - started).count();
    const double aiTime = actions[0].milliseconds + actions[1].milliseconds;
    match.record(aPlayer, winner, ply, time, actions);
    gameLog << "[wynik_partii_" << game << "]\nrezultat = " << (winner ? "Wygrana" : "Remis")
            << "\nzwyciezca = " << (winner == 0 ? "Brak" : (winner == aPlayer ? a.legacyLabel : b.legacyLabel))
            << "\nliczba_ruchow_z_otwarciem = " << ply << "\nzwyciezca_gracz = " << winner
            << "\nczas_partii_ms = " << number(time, 6) << "\nsuma_czasu_ai_ms = " << number(aiTime, 6)
            << "\nruchy_awaryjne = " << actions[0].interrupted + actions[1].interrupted << "\n\n";
    log << gameLog.str();
    log.flush();
    publishHtml(study);
}

double mean(const std::vector<Number>& values) {

    if (values.empty()) return 0;
    std::sort(values.begin(), values.end());
    const auto middle = values.size() / 2;
    if (values.size() % 2) return static_cast<double>(values[middle]);
    return (static_cast<double>(values[middle - 1]) + values[middle]) / 2;
}

struct Moves {
    int count = 0;
    int interrupted = 0;
    double milliseconds = 0;

    void record(double time, bool complete) {
        ++count;
        milliseconds += time;
        if (!complete) ++interrupted;
    }
    void add(const Moves& other) {
        count += other.count;
        interrupted += other.interrupted;

struct Results {
    int wins = 0;
    int losses = 0;
    int draws = 0;
    std::vector<int> lengths;
    double gameMs = 0;
    double gameAiMs = 0;
    Moves moves{};

    void record(int outcome, int length, double elapsed, double aiMs, const Moves& ownMoves) {
        if (outcome > 0) ++wins;
        else if (outcome < 0) ++losses;
        else ++draws;
        lengths.push_back(length);
        gameMs += elapsed;
        gameAiMs += aiMs;
        moves.add(ownMoves);
    }

    void add(const Results& other) {
        wins += other.wins;
        losses += other.losses;
        draws += other.draws;
        lengths.insert(lengths.end(), other.lengths.begin(), other.lengths.end());
        gameMs += other.gameMs;
        gameAiMs += other.gameAiMs;
        moves.add(other.moves);
    }

    int games() const { return wins + losses + draws; }
    double winRate() const { return percent(wins, games()); }
    double averageGame() const { return games() ? gameMs / games() : 0; }
    double averageGameAi() const { return games() ? gameAiMs / games() : 0; }
};

    int winsO = 0;

    Results strategy(int side) const {
        Results result = role[side][0];
        result.add(role[side][1]);
        return result;
    }

    void record(int aPlayer, int winner, int length, double elapsed, const std::array<Moves, 2>& actions) {
        int aRole = aPlayer - 1;
        int bRole = 1 - aRole;
        int outcome = winner == 0 ? 0 : (winner == aPlayer ? 1 : -1);
        double aiMs = actions[0].milliseconds + actions[1].milliseconds;
        role[0][aRole].record(outcome, length, elapsed, aiMs, actions[0]);
        role[1][bRole].record(-outcome, length, elapsed, aiMs, actions[1]);
        lengths.push_back(length);
        gameMs += elapsed;
        moves.add(actions[0]);
        moves.add(actions[1]);
        if (winner == 1) ++winsX;
        else if (winner == 2) ++winsO;
        else ++draws;
    }
};

struct Study {
    int maxDepth;
    int pairs;
    bool finished = false;
    std::string date;
    std::vector<Benchmark> benchmarks;
    std::vector<Match> matches;

    int plannedGames() const { return pairs * 24; }
    const Benchmark* find(int size, int plies, int depth, bool pruned) const {
        auto same = [&](const Benchmark& b) {
            return b.size == size && b.plies == plies && b.depth == depth && b.pruned == pruned;
        };
        auto item = std::find_if(benchmarks.begin(), benchmarks.end(), same);
        return item == benchmarks.end() ? nullptr : &*item;
    }
};

struct Comparison {
    const Benchmark* plain;
    const Benchmark* pruned;

    bool equivalent() const {
        return plain->consistent && pruned->consistent &&
               plain->column == pruned->column && plain->score == pruned->score;
    }
    double speedup() const { return median(plain->times) / median(pruned->times); }
    double reduction() const { return 100 * (1 - mean(pruned->nodes) / mean(plain->nodes)); }
};

inline std::vector<Comparison> comparisons(const Study& study) {
    std::vector<Comparison> result;
    for (const auto& sample : study.benchmarks) {
        if (sample.pruned || !sample.full()) continue;
        const auto* pruned = study.find(sample.size, sample.plies, sample.depth, true);
        if (pruned && pruned->full()) result.push_back({&sample, pruned});
    }
    return result;
}

struct Standing {
    int bot;
    std::array<Results, 2> role;
    Results result() const {
        Results all = role[0];
        all.add(role[1]);
        return all;
    }
};

inline std::vector<Standing> standings(const Study& study, int size, bool depths) {
    std::vector<Standing> result;
    for (int bot : depths ? std::array<int, 3>{3, 1, 4} : std::array<int, 3>{0, 1, 2}) {
        Standing standing{bot, {}};
        for (const auto& match : study.matches) {
            if (match.size != size || match.depths != depths) continue;
            for (int side : {0, 1}) {
                if (match.bot[side] != bot) continue;
                standing.role[0].add(match.role[side][0]);
                standing.role[1].add(match.role[side][1]);
            }
        }
        if (standing.role[0].games() + standing.role[1].games()) result.push_back(std::move(standing));
    }
    std::stable_sort(result.begin(), result.end(), [](const Standing& a, const Standing& b) {
        const int aGames = a.role[0].games() + a.role[1].games();
        const int bGames = b.role[0].games() + b.role[1].games();
        return (a.role[0].wins + a.role[1].wins) * bGames >
               (b.role[0].wins + b.role[1].wins) * aGames;
    });
    return result;
}

inline std::vector<std::string> findings(const Study& study) {
    std::vector<std::string> text;
    Comparison fastest{nullptr, nullptr};
    int disagreements = 0;
    for (const auto& c : comparisons(study)) {
        if (!c.equivalent()) ++disagreements;
        else if (median(c.pruned->times) > 0 && (!fastest.plain || c.speedup() > fastest.speedup())) fastest = c;
    }
    if (fastest.plain) {
        const auto& b = *fastest.plain;
        text.push_back("Najwieksze przyspieszenie Alpha-Beta: " + number(fastest.speedup(), 2) + "x, plansza " +
            boardLabel(b.size) + ", otwarcie " + integer(b.plies) + ", d=" + integer(b.depth) +
            ", redukcja wezlow " + number(fastest.reduction(), 2) + "%.");
    }
    if (disagreements) text.push_back("Rozbieznosci ruchu lub oceny w pelnych porownaniach: " + integer(disagreements) + ".");
    for (int size : {0, 1}) for (bool depths : {false, true}) {
        const auto rank = standings(study, size, depths);
        if (rank.empty()) continue;
        const auto best = rank.front().result();
        std::string leaders;
        for (const auto& item : rank) {
            const auto r = item.result();
            if (r.wins * best.games() != best.wins * r.games()) break;
            if (!leaders.empty()) leaders += " / ";
            leaders += std::string(bots[item.bot].label) + " (" + integer(r.wins) + "/" + integer(r.games()) + ")";
        }
        text.push_back(std::string("Lider wg odsetka wygranych, ") + seriesLabel(depths) + ", " +
                       boardLabel(size) + ": " + leaders + ", " + number(best.winRate(), 2) + "%.");
    }
    for (const auto& row : boardEffect(study).rows) {
        if (row[3] == "-") continue;
        text.push_back("Role po otwarciu, " + row[1] + ", " + row[0] + ": X " + row[3] +
                       "% wygranych, O " + row[4] + "%, remisy " + row[5] + "%.");
    }
    const auto* small = study.find(0, 0, 3, false);
    const auto* large = study.find(1, 0, 3, false);
    if (small && large && small->full() && large->full() && median(small->times) > 0) {
        text.push_back("Pusta plansza, Minimax d=3: 8 x 9 / 6 x 7 = " +
            number(median(large->times) / median(small->times), 2) + "x mediany czasu i " +
            number(median(large->nodes) / median(small->nodes), 2) +
            "x wezlow. Zmienia sie liczba kolumn i koszt stanu.");
    }
    for (const auto& row : limits(study).rows) {
        std::string message = row[0] + ", otwarcie " + row[1] + ", " + row[2] + ": ";
        if (row[5] != "-") message += "prog 1000 ms na d=" + row[5] + " (mediana " + row[7] + " ms).";

        else if (row[3] != "-") message += "prog nieosiagniety do ukonczonego d=" + row[3] + ".";
        else continue;
        text.push_back(message);
    }
    return text;
}

inline void atomicReport(const std::filesystem::path& destination, const std::string& contents) {
    auto temp = destination;
    temp += ".tmp";
    {
        std::ofstream file(temp, std::ios::binary);
        file.exceptions(std::ios::failbit | std::ios::badbit);
        file << contents;
        file.close();
    }
#ifdef _WIN32
    // A reader or Windows file scanner can briefly deny replacement.
    for (int attempt = 0; ; ++attempt) {
        if (MoveFileExW(temp.c_str(), destination.c_str(), MOVEFILE_REPLACE_EXISTING | MOVEFILE_WRITE_THROUGH)) break;
        const auto error = GetLastError();
        const bool busy = error == ERROR_ACCESS_DENIED || error == ERROR_SHARING_VIOLATION ||
                          error == ERROR_LOCK_VIOLATION;
        if (!busy || attempt == 9)
            throw std::system_error(static_cast<int>(error), std::system_category(), destination.string());
        std::this_thread::sleep_for(std::chrono::milliseconds(20 * (attempt + 1)));
    }
#else
    std::filesystem::rename(temp, destination);
#endif
}

inline void printTable(const Table& table, const std::vector<std::size_t>& selection) {
    if (table.rows.empty()) return;
    std::vector<std::size_t> widths;
    for (auto column : selection) {
        std::size_t width = table.columns[column].size();
        for (const auto& row : table.rows) width = std::max(width, row[column].size());
        widths.push_back(width);
    }
    auto print = [&](const Row& row) {
        for (std::size_t i = 0; i < selection.size(); ++i) {
            std::cout << std::left << std::setw(static_cast<int>(widths[i])) << row[selection[i]];
            if (i + 1 != selection.size()) std::cout << " | ";
        }
        std::cout << '\n';
    };
    print(table.columns);
    for (const auto& row : table.rows) print(row);
}

inline std::string htmlEscape(const std::string& value) {
    std::string text;
    for (const char ch : value) {
        switch (ch) {
        case '&': text += "&amp;"; break;
        case '<': text += "&lt;"; break;
        case '>': text += "&gt;"; break;
        case '"': text += "&quot;"; break;
        default: text += ch;
        }
    }
    return text;
}

Uruchomcie pełny eksperyment

  1. Wybierzcie 3 turniej AI i wpiszcie 25 par. Menu przyjmuje od 1 do 50 par. Przy 25 parach powstaje 50 partii na pojedynek i planszę, czyli łącznie 600 partii w dwóch seriach.

  3. Po pomiarach program rozgrywa serię główną: zachłanna, Alpha-Beta d=3 i Monte Carlo z 30 symulacjami na legalną kolumnę. W drugiej serii testuje Alpha-Beta w trzech zestawieniach: d=1 kontra 3, d=1 kontra 5 i d=3 kontra 5.
  4. Każda para rozgrywa dwie partie na identycznym otwarciu po sześciu ruchach z zamianą X i O. Pierwszy ruch wykonany przez AI należy do X. Ziarna i konkretne kolumny otwarcia są zapisane w logu. Wnioski o roli gracza dotyczą tych otwarć.

Jak porównać wyniki w sprawozdaniu
  1. Zapiszcie procesor, system, kompilator i ustawienia kompilacji. Pokaz dostępny w katalogu pochodzi z jednego uruchomienia. Czasy mogą się zmienić przy kolejnym badaniu.
  2. Porównujcie Minimax i Alpha-Beta dla tej samej planszy, pozycji oraz głębokości. Redukcja węzłów to 100 × (1 − węzły z cięciami / węzły bez cięć). Przyspieszenie to mediana bez cięć / mediana z cięciami. Sprawdźcie też zgodność wybranej kolumny i oceny.
  3. Podajcie ostatnią pełną głębokość i granicę dla każdej konfiguracji. Jeśli mediana osiągnęła próg, podajcie głębokość i wartość. Jeśli wyszukiwanie przerwał limit, odnotujcie przerwanie. Jeśli próg nie został osiągnięty do d=12, podajcie ten zakres.
  4. Dla każdej strategii wygrane, przegrane i remisy dzielcie przez liczbę jej partii. Porównujcie stronę X i O przeciw temu samemu rywalowi. Oddzielnie omówcie ranking główny oraz serię głębokości i podajcie liczbę ruchów awaryjnych.
  5. Plansza 8 × 9 ma więcej możliwych kolumn i pól niż 6 × 7. Wzrost liczby węzłów i czasu opisuje łączny efekt tych zmian.

Pytania do przećwiczenia
  • Co jest węzłem drzewa, a co jego krawędzią? Węzłem jest stan Board, krawędzią jeden legalny ruch.
  • Dlaczego funkcja wywołuje samą siebie? Każdy ruch prowadzi do mniejszego podproblemu, z głębokością zmniejszoną o jeden.
  • Kiedy kończy się rekurencja? Po wygranej, remisie, osiągnięciu głębokości albo limitu czasu. Ostatni przypadek jest oznaczony jako nieukończony.
  • Dlaczego kopiujemy planszę? Żeby sprawdzenie jednego wariantu nie zmieniało stanu rzeczywistej gry ani innych gałęzi.
  • Po co unique_ptr i wirtualny destruktor? Gracz może posiadać obiekt jednej z różnych strategii, usuwany automatycznie przez wspólny typ.
  • Czym pusty optional różni się od wartości 0? Pusty oznacza brak wyniku, a 0 jest konkretną zapisaną wartością, tutaj remisem.
  • Czy Alpha-Beta daje inną strategię? Pomija zbędne gałęzie Minimaxu przy tej samej głębokości i ocenie. Trzecią metodą w projekcie jest Monte Carlo.
  • Jak porównano głębokości Alpha-Beta? Na tych samych otwarciach rozegrano po dwie partie z zamianą stron w każdej parze głębokości 1, 3 i 5.
  • Co znaczy granica podejścia siłowego? W tym badaniu jest to osiągnięcie ustalonego progu czasu na określonych pozycjach i komputerze. Nie jest uniwersalną granicą całej gry.
